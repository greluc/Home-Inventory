Third-party licence notices, reproduced verbatim
================================================

This identifier marks a file that is an AGGREGATE OF OTHER PEOPLE'S LICENCE
NOTICES rather than a work of this project. It grants nothing and licenses
nothing on its own.

Each such file is generated by `tools/notices.py` from what one distributed
artifact of this repository actually carries, and it names, for every component
in that artifact:

  * the component and its version,
  * the SPDX identifier or identifiers it is published under, and
  * the verbatim text of the licence and notice files that component ships.

The licence that applies to any part of such a file is therefore the one named
beside that part, and no single identifier can stand for the whole. That is what
this reference exists to say. SPDX's `NOASSERTION` expresses the same thing but
is not a licence identifier, which is why a reference is used instead.

These files must never be edited by hand. Editing somebody else's licence notice
misrepresents it, and the generator overwrites the file on the next run anyway:
CI regenerates every one of them and fails on any difference (REQ-CON-013).

The same applies to the files under `tools/notices/licences/` and
`tools/notices/overrides/`, which are the canonical texts those notices
reproduce and the notices of the few components that publish none inside their
own artifact. Each of those files records where it was taken from.
