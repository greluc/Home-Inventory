Empty, no-results, error and first-run all use this. Only the words and the icon change.

```jsx
<EmptyState icon="package" title="Noch keine Artikel an diesem Ort" action={<Button variant="primary" icon="scan-line">Etikett scannen</Button>}>
  Drucke einen Bogen Etiketten und scanne sie ein — drei Handgriffe pro Artikel.
</EmptyState>
```
