Six field types in one control. Numeric variants right-align and use tabular figures so a column of quantities lines up.

```jsx
<TextInput type="text" placeholder="Name" />
<TextInput type="integer" value={12} />
<TextInput type="multiline" rows={4} />
<TextInput type="text" mono value="7Q2M-4X9K-D2F" readOnly />
```
